# 🚗 Uber Clone (HTML & CSS)

A front-end **Uber UI clone** built entirely using **HTML5 and CSS3**.  
This project focuses on replicating the visual design and layout of the Uber interface while practicing modern CSS techniques and responsive design.

---

## ✨ Features

- Clean and minimal Uber-inspired user interface
- Responsive layout using pure CSS
- Well-structured and semantic HTML
- Pixel-focused UI cloning from a real-world application
- No JavaScript, no frameworks — **100% HTML & CSS**

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**

---

## 🎯 Purpose of the Project

This project was created to:
- Practice front-end UI development
- Improve CSS layout skills (Flexbox & Grid)
- Understand real-world UI structure
- Build confidence in cloning production-level designs
